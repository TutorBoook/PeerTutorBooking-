# Project Scope

## Project Objective

The objective of TutorBook is to provide a software system that connects students who need academic assistance with peer tutors. The system will allow students to find tutors and book tutoring sessions, while allowing tutors to manage their availability and scheduled sessions.

## Target Users

The main users of TutorBook are:

- Students looking for tutoring
- Peer tutors
- System administrators

## In-Scope Features

The current version of TutorBook will include:

- User registration and login
- Student and tutor profiles
- Searching and browsing available tutors
- Tutor availability management
- Booking tutoring sessions
- Viewing scheduled sessions
- Modifying or cancelling bookings
- Managing upcoming tutoring sessions

## Out-of-Scope Features

The following features will not be included in the current version:

- Online payment processing
- Video-call tutoring
- AI-generated tutoring
- Integration with university registration systems
- Automatic academic advising
- Native mobile applications

## Major Deliverables

The major deliverables of the project are:

- A working TutorBook software system
- User interface for students and tutors
- Tutor search and booking functionality
- Availability and session management functionality
- Project documentation
- Source code stored in the GitHub repository
