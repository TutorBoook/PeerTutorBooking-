# Initial Feasibility Study

## Technical Feasibility

TutorBook is technically feasible because it can be developed using the software tools and programming skills available to the team. The main features such as user accounts, tutor searching, availability, and booking can be developed without needing special hardware.

## Economic Feasibility

The project is economically feasible because it does not require expensive software or hardware. Most of the tools needed for development are free or already available to the team. The main resource required is the time spent developing and testing the system.

## Operational Feasibility

TutorBook is operationally feasible because it solves a real problem for students who need academic help. Students can use the system to find tutors and book sessions, while tutors can manage their availability and sessions in one place.

## Schedule Feasibility

The project is feasible within the available course time because the system can be developed in increments. The team can complete the main features first and add other features later if there is enough time.

## Overall Feasibility

Overall, TutorBook appears to be feasible. The system can be developed using the available tools, skills, and time. The main challenges may be schedule delays, team availability, and combining different parts of the system.
