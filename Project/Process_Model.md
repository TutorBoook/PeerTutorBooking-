# Software Process Model

## Selected Software Process Model
The selected software process model for TutorBook is the Incremental Model.

## Justification
The Incremental Model is suitable for TutorBook because the system can be divided into small and manageable parts. Each increment can focus on a specific group of features, such as user accounts, tutor searching, availability management, and session booking.
This allows the team to develop a working version of the system early and then add more features in later increments. It also makes it easier to receive feedback, manage risks, and make changes between versions.

## Overheads / Drawbacks
The Incremental Model requires detailed planning before development begins. Integration between different increments can also become complicated and may increase development time and effort.

## Strategy for Managing Overheads / Drawbacks
The team will clearly define the main system structure and the responsibilities of each increment before development begins. Each increment will be tested before it is integrated with the rest of the system.
The team will also use regular communication and GitHub to coordinate changes and reduce integration problems.
