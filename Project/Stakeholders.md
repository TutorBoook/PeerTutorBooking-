# Stakeholder Analysis

| Stakeholder | Role | Interest / Expectations | Influence on the System | How the System Affects the Stakeholder |
|---|---|---|---|---|
| Students | Use TutorBook to find tutors and book sessions | They want an easy way to find help and manage bookings | Their feedback can affect the features of the system | Makes it easier for them to find tutoring |
| Peer Tutors | Provide tutoring and manage their availability | They want an easy way to show availability and manage sessions | Their needs affect the booking and availability features | Helps them organize their tutoring sessions |
| System Administrator | Manages users and the system | Wants the system to work correctly and be easy to manage | Can control and manage system data and users | Gives them one place to manage the system |
| Development Team | Designs, develops, and tests TutorBook | Wants to complete the project successfully | Makes decisions about how the system is developed | Gives the team experience developing a real software project |
| University | May support or use the system for peer tutoring | Wants students to have better access to academic support | May affect rules or requirements for the system | Could improve how peer tutoring is organized |
